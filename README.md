# Python-Projects

1. Quiz App
- A simple quiz game that asks random general knowledge questions.
- Uses random to shuffle questions.
- Compares user answers and gives feedback.
- Displays total score and performance message at the end.


2. BMI Calculator
- A program that calculates the Body Mass Index (BMI).
- Takes height and weight as input.
- Calculates BMI using the formula weight / (height ** 2).
- Displays BMI category and a short health tip.


3. Password Strength Tester
- Checks how strong a password is based on several factors.
- Tests for length, uppercase, lowercase, numbers, and symbols.
- Gives a score and feedback for improvement.
- Warns against using common weak passwords.


4. Coin Flipper with AI Prediction
- A virtual coin flipper that includes a simple AI predictor.
- AI predicts Heads or Tails based on previous flips.
- Shows prediction accuracy after each round.
- User can continue flipping until they stop.


5. Study Chat Bot
- An interactive chatbot that helps with study motivation.
- Greets the user and saves their name.
- Gives study tips, motivational quotes, and definitions.
- Responds naturally to user input.
